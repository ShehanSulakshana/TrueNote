## 📌 About The Project

**TrueNote** is a cross-platform mobile app built with Flutter, focusing on performance, clean design, and privacy-first note management.

This repository serves as a public development log to track progress, architecture, and code evolution.


> [!IMPORTANT]
>- **Work In Progress:** The structure and code in this repository are actively changing. Build instructions and public documentation will be updated as the app approaches a stable initial release.
